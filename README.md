# GitHub 看得懂

一个面向中文初学者的 GitHub 网页练习站。保留英文界面用词，点击控件旁的 `?`，中文说明就会显示在英文下方。

**[打开练习站](https://li-1116.github.io/github-practice/)** · [查看项目计划](PLAN.md)

## 怎么用

- 从「练习路线」开始。可以练习建仓、建分支、编辑文件、提交和合并，也可以练习处理问题和通知。
- 用「页面和按钮目录」搜索中英文词汇，查找对应页面和控件。左上角菜单还提供词汇表和小测验。
- 练习只操作虚构数据。进度保存在当前浏览器，可以在练习路线页重置。

## 本地运行

下载或克隆本仓库，在浏览器打开 `index.html`。无需安装依赖或启动后端。也可以使用本地静态服务器预览。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面入口和导航 |
| `app.js` | 模拟界面、词汇表与小测验 |
| `practice.js` | 页面目录、练习流程和浏览器进度 |
| `styles.css` | 页面样式和窄屏布局 |

线上版本由 GitHub Pages 从 `main` 分支根目录发布。
